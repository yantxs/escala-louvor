# Escala de Louvor · COMBC

Página para adicionar a escala do Ministério de Louvor à agenda (iPhone, Android, Outlook ou qualquer app que aceite iCal).

- `?b=<banda>` abre a página de uma banda; sem parâmetro, lista todas.
- Os feeds vêm das agendas públicas do Google (fonte da escala). Os IDs estão em `agendas.js`.
